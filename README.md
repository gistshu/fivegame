# Zen Gomoku 50x50

一個基於 React 與 TypeScript 開發的高性能 50x50 五子棋遊戲。具備專業級的視覺設計、三種難度的 AI 對手，以及流暢的畫布繪圖效能。

## Prompt

請製作一個可以和電腦對戰的5子棋遊戲，棋盤為50x50，難度共三級
開始畫面可以用上下鍵選難度
按下space按鍵後開始
電腦用黑色棋，玩家用白色
玩家使用滑鼠點選棋子的位置
五子棋的邏輯請自行上網找尋
每局結束後可顯示黑白棋子的數量
按下enter按鈕則重回主畫面

## 🌟 核心特色

- **50x50 巨大棋盤**：挑戰遠超傳統 15x15 棋盤的戰略深度。
- **三級智慧 AI**：
  - **新手 (Easy)**：隨機性較高，適合初學者練習基本規則。
  - **高手 (Normal)**：平衡進攻與防守，能識別基本的四連與活三。
  - **大師 (Hard)**：積極進攻，能精準計算複雜的連珠陷阱。
- **極致效能**：採用 HTML5 Canvas 渲染引擎，即使在 50x50 的高密度棋盤下也能保持 60 FPS 的操作順暢度。
- **現代化介面**：使用 Tailwind CSS 打造的深色模式風格，具備毛玻璃效果與流暢的過場動畫。
- **全平台適應**：響應式畫布設計，支援不同解析度的螢幕。

## 🎮 操作指南

### 主選單
- **方向鍵 (↑ / ↓)**：切換難度。
- **空白鍵 (SPACE)**：開始遊戲。

### 遊戲中
- **滑鼠左鍵**：在交叉點放置棋子。
- **頂部狀態欄**：顯示當前回合、雙方棋子總數及難度設定。
- **退出按鈕**：隨時返回主選單。

### 結算畫面
- **ENTER 鍵**：快速返回主選單重新開始。

## 🧠 AI 邏輯說明

本遊戲的 AI 採用權重評估法。它會掃描棋盤上所有具備潛力的落子點，並根據以下因素計算分值：
1. **進攻權重**：自身連珠的威脅程度（如活三、沖四）。
2. **防守權重**：阻斷玩家連珠的必要性。
3. **距離權重**：優先考慮已有棋子周圍的區域，大幅提升大棋盤下的計算效能。
